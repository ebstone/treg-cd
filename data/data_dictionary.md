# Data Dictionary

Source data for the Treg-vs-biologics Crohn's disease CEA (Jadambaa, Stone,
Abraham), pulled together from the manuscript, the Aliyev et al. 2019
(*Pharmacotherapy*) supplementary appendices, and the live `IBD_CEA_v6_PSA.xlsm`
model workbook.

## Known open issues (not resolved by this data pull — see prior project notes)

- The `Economically Justifiable Price` sheet in the workbook currently computes **$185,625**, which does not match the manuscript's stated EJP of **$95,382**. Not corrected here; flagged for the team.
- The maintenance Markov sheets do not implement Aliyev's 2-year biologic-duration cap (patients stay on biologic-specific transition probabilities for the full ~6.15-year horizon rather than switching to CT-derived probabilities after cycle 13).
- The Treg base-case surgery-state transition row does not follow the same redistribution rule as the Alpha/Beta scenario rows (see `model_maintenance_transition_probabilities.csv`, TREG base scenario, `from_state=Surgery`).
- **Resolved 2026-08-04:** the Surgery health-state cost previously used an HCUP colectomy episode cost (~$35,518) applied every cycle of Surgery-state occupancy. This mischaracterized Aliyev's Surgery state, which represents a claims-average PMPM cost across all CD-related surgeries/procedures (most outpatient), not a single major inpatient operation. `model_health_state_costs.csv` now uses Aliyev's own per-cycle figure ($884, 2017 USD → $1,152.29, 2025 USD), applied identically across TREG/UST/IFX/CT. See `docs/model_audit_v6.md` finding A9 for full detail, including a residual, inherited (not new) reconciliation gap between Aliyev's $884 and Suppl. Table 2's $1,475 PMPM.
- **Resolved 2026-08-04:** `model_health_state_costs.csv`'s cost column was still named `cost_per_8wk_cycle_usd_2025`, a leftover from the project's original 8-week-cycle design (analysis_plan.md §4.1). That design was dropped in favor of Aliyev's native 2-week cycle throughout (`R/00_derive_transition_probs.R`'s third-revision header comment; `docs/analysis_plan.md` §8's 2026-08-04 revision). Checked the actual figures against this: UST's Mod/Sev cost ($282.86) equals Aliyev's $217 (2017 USD) inflated by the model's standard ≈1.3035 factor with **no additional cycle-length multiplier**, and CT's flat $88 likewise matches $67 × ~1.306 directly — confirming the values already represent Aliyev's native per-2-week-cycle costs, not per-8-week costs mislabeled as such. **No values changed** — renamed the column to `cost_per_2wk_cycle_usd_2025` to match reality. This does not touch the separate, already-tracked issue that the Treg arm's Mod/Sev Resp/Mild/Remission costs are un-inflated 2017 dollars while other arms use 2025 dollars (Decision 5, `docs/analysis_plan.md` §8/§15) — that remains open.
